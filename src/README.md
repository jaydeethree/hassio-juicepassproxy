# Home Assistant App: JuicePassProxy

Run [JuicePassProxy](https://github.com/JuiceRescue/juicepassproxy) as a Home Assistant app to locally monitor and control your JuiceBox EV charger via MQTT auto-discovery.

> **Note:** This project is **NOT** affiliated with JuicePassProxy or the JuiceRescue Organization — it is an unofficial Home Assistant app wrapper.

See the **Documentation** tab after installing (or visit the [GitHub repository](https://github.com/jaydeethree/hassio-juicepassproxy)) for setup and network redirection instructions.
